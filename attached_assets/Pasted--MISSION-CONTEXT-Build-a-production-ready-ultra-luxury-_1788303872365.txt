# MISSION & CONTEXT
Build a production-ready, ultra-luxury Real Estate Web Portal and Admin Management Platform for "Lopes Signature" (an exclusive high-end real estate brand).
The user experience must balance cinematic dark-luxury aesthetics with high-performance UI components, interactive catalog filtering, individual landing page linking, and a tracking/metrics dashboard.

Strictly adhere to the design tokens and layout specifications provided in the attached `design-tokens.json` and visual references.

---

# TECH STACK & SYSTEM ARCHITECTURE
- Framework: React (TypeScript) + Vite / Next.js
- Styling: Tailwind CSS configured with all tokens from the JSON (colors, border radiuses, hairpins, shadows, and fonts)
- UI Library / Primitives: Radix UI / Shadcn UI / Lucide React (stroke width 1.5px)
- Animations: Framer Motion (using the specified easing: cubic-bezier(0.16, 1, 0.3, 1))
- State Management / Mock Data: Mock service simulating catalog data, LP URLs, analytics, and pixel tracking settings.

### 2. Hero Section & Category Bar

- Floating Category Pill Bar at the bottom of the hero: Interactive pills (Apartamentos, Coberturas, Mansões, Terrenos, Lançamentos) with minimalist gold icons and active highlight states.

- Split Horizontal Property Cards:
  - Left: Image gallery with thumbnail counter (e.g. 1/35) and smooth hover zoom.
  - Right: Typographic hierarchy with Title, Gold Price, technical specs icons, description excerpt, bookmark button, and "Ver Detalhes / Acessar LP" button linking to the dedicated LP route.

### 5. Team of Specialists ("O Programa Lopes Signature")
- Dark luxury grid presenting elite advisors, badge pins, credentials, direct WhatsApp scheduling, and bio.

### 6. Admin Management & Tracking Hub (`/admin`)
Implement a dedicated, responsive Dark Mode Dashboard with a collapsible 260px sidebar:
- **Tab 1: Analytics & Metrics:**
  - Metric cards: Visitas Totais, Cliques em Botões de WhatsApp, Visualizações de LPs, Conversões de Formulário.
  - Charts showing lead traffic and page views over time.
- **Tab 2: Gerenciador de Catálogo:**
  - Table / Grid view of all properties.
  - Modal to Add/Edit Property: Title, Description, Price, Specs, Category, Badges ("EXCLUSIVO", "NOVO"), Image Gallery URLs, and **"URL da Landing Page Dedicada"** (connecting the Antigravity-built LP to the institutional item).
- **Tab 3: Tracking & Pixels Hub:**
  - Direct input fields with test/save states for:
    - Meta Pixel ID (`Pixel ID` input + toggle enable/disable)
    - Google Tag Manager (GTM Container ID)
    - Google Analytics 4 (Measurement ID `G-XXXXXXX`)

- **Tab 4: Gestão de Leads:**

# DESIGN IMPLEMENTATION RULES
1. **Dark Luxury Atmosphere:** Dominant background `#0A0A0A`, elevated cards `#1A1A1A`, gold hairline strokes (`rgba(212, 175, 55, 0.25)`). Never use generic flat blues or saturated grays.
2. **Typography Hierarchy:** Clean geometric sans for body (`Plus Jakarta Sans` or `Inter`) + refined serif/display accents for titles (`Cormorant Garamond` or `Playfair Display`).
3. **Motion:** Elegant micro-interactions (soft glow on hover, card lift `-4px`, stagger transitions on scroll reveal).
4. **Modularity:** Keep components clean, typed, and well-separated into `/components`, `/pages`, `/types`, and `/mock` so they can be easily customized and imported into Antigravity IDE.
